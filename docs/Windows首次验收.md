# Windows 首次验收

第一次在 Windows 上使用时，按这份清单从头到尾走一遍。全部通过，才说明项目在你的电脑上真正可用、达到预期。

**为什么需要这一步**：开发和自动化测试都在没有显卡、没有声卡的 Linux 服务器上完成。代码逻辑、口型对齐和画质已经验证过，但下面这些只能在你的电脑上确认：

- 显卡能不能实时生成，每秒 25 帧
- Windows 上的安装脚本能不能正常运行（这些脚本还没有在 Windows 上跑过）
- 真实的麦克风、虚拟声卡、RVC、OBS 接进来以后是否正常
- 实际延迟、音画同步，以及长时间运行是否稳定

一次大约需要 1 到 2 小时，主要花在下载和试播上。

## 每一步都记下结果

| 步骤 | 通过标准 | 结果 |
|---|---|---|
| 1. 安装 | `install.bat` 跑完不报错；`doctor.bat` 里没有“问题”项 | |
| 2. 离线画质 | 两个测试视频口型对得上，MuseTalk 画质可以接受 | |
| 3. 显卡速度 | MuseTalk 在口型卡上占实时预算 **70% 以下** | |
| 4. 实时口型 | 说话时帧率稳定在 25 左右，卡顿次数不再增长 | |
| 5. 音画同步 | OBS 录像里，闭嘴音（b/p/m）和嘴唇闭合对得上 | |
| 6. 稳定性 | 连续试播 30 分钟，延迟不变大、画面不卡死 | |

## 1. 安装

1. 安装 [Python 3.11](https://www.python.org/downloads/)，勾选 “Add python.exe to PATH”。
2. 克隆或下载本项目。**路径里最好不要有中文和空格**，比如放在 `D:\AIAvatarStream`。
3. RTX 50 系显卡：用记事本打开 `scripts\install.bat`，把 `cu124` 改成 `cu128`。
4. 国内网络：打开命令行，先执行 `set HF_ENDPOINT=https://hf-mirror.com`，再在同一个窗口里运行 `scripts\install.bat`。
5. 双击 `scripts\install.bat`。它要下载 GPU 版 PyTorch（约 2.5 GB）和模型（约 4.3 GB），最后给示例形象生成 MuseTalk 数据。
6. 双击 `scripts\doctor.bat`，查看检查结果。

**通过**：`install.bat` 最后显示 `CUDA 可用: True` 和你的显卡型号；`doctor.bat` 里没有标“问题”的行。现在还没装虚拟声卡，所以“虚拟声卡”那一行标“注意”是正常的。

**常见问题**

| 现象 | 处理 |
|---|---|
| `CUDA 可用: False` | 装成了 CPU 版 PyTorch。检查 `install.bat` 里的 `cu124` / `cu128` 和显卡是否匹配，删掉 `.venv` 文件夹后重新运行 |
| 下载很慢或中断 | 用上面的 `HF_ENDPOINT` 镜像。重新运行 `install.bat` 会跳过已经下好的文件 |
| 命令行里中文显示成乱码 | 不影响使用。在命令行属性里把字体改成“新宋体”或“Consolas”可以改善 |

## 2. 离线画质

双击 `scripts\test_render.bat`，它会用自带的测试语音分别生成：

- `output\test_musetalk.mp4`
- `output\test_wav2lip.mp4`

**通过**：两个视频都有声音，口型跟着说话在动；MuseTalk 那个嘴部清晰，看得到牙齿。命令行里会打印“推理 xx 帧/秒”，MuseTalk 那一行最好在 30 以上。

## 3. 显卡速度

双击 `scripts\setup_gpus.bat`：

1. 口型模型选 **2（MuseTalk）**，变声器选 **1（RVC）**。
2. 它会在每张卡上实测 MuseTalk，打印“占实时预算 xx%”。
3. 看推荐方案，回车接受，或者按你的想法改。
4. 最后填 RVC 的启动脚本路径，例如 `D:\RVC\go-realtime-gui.bat`。

**通过**：分给口型的那张卡，占实时预算在 **70% 以下**。

**不通过怎么办**：

- 70% 到 100%：能跑，但遇到变声器抢资源可能会卡。把 `start_live.bat` 里的 `BATCH` 调到 8 再测。
- 超过 100%：这张卡跑不动 MuseTalk 实时直播。先用 `ENGINE=wav2lip`，再把测出来的数字发给我，看看能不能做“两张卡轮流算”。

## 4. 实时口型

1. 按 [直播搭建指南](直播搭建指南.md) 第 1、2 步装好 VB-CABLE（装完要重启）和 RVC。
2. 用 `scripts\start_voice_changer.bat` 启动 RVC：输入选你的麦克风，输出选 `CABLE Input`，打开监听。
3. 双击 `scripts\start_live.bat`，浏览器会打开状态页。
4. 对着麦克风正常说话，说 1 分钟左右。

**通过**：

- 说话时“说话”变成“是”，预览里嘴在动；停下来以后嘴闭上
- 帧率稳定在 24 到 26
- “卡顿次数”不再增长（刚启动时涨几次是正常的）
- 打开任务管理器的“性能”页，两张卡各自都有占用

**顺手记下**：状态页上的“平均延迟”，下一步要用。

## 5. 音画同步

1. 按 [直播搭建指南](直播搭建指南.md) 第 4 步设置 OBS：浏览器源加音频输入采集，同步偏移填状态页的值。
2. OBS 点“开始录制”，清楚地说几句带“爸爸、跑步、妈妈”这类闭嘴音的话，录 20 秒。
3. 回放录像。

**通过**：每次发 b、p、m 音时，嘴唇刚好合上。差一点的话，按指南把偏移加减 40 到 80 毫秒，重录一次。

## 6. 稳定性

正常开着 RVC、口型程序和 OBS，对着麦克风断断续续说话 30 分钟。可以用 OBS 录一份，或者开一场不公开的测试直播。

**通过**：

- 30 分钟后，状态页的平均延迟和刚开始时差不多，没有越来越大
- 画面没有卡死，声音没有断
- 任务管理器里显存占用没有一直上涨

## 遇到问题时，发这些给我

1. 双击 `scripts\doctor.bat`，把 `output\diagnostics.txt` 的内容发过来。
2. 出错的那个命令行窗口里的全部文字（右键标题栏 → 编辑 → 全选，再复制）。
3. 卡在第几步，以及你做了什么操作。

更快的方式是在电脑上开 Remote Control：在项目目录运行 `claude remote-control`，我可以直接在你的电脑上执行命令、看报错、当场修复。
