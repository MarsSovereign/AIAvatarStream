# 形象制作指南

数字人不说话时播放的是一段“待机视频”。说话时，程序只重画嘴巴和下巴，眼睛、头部动作和背景都来自这段视频。所以**待机视频的质量，直接决定直播效果**。

制作分四步：准备视频 → 生成形象 → 生成 MuseTalk 数据 → 检查效果。

## 1. 准备待机视频

### 硬性要求

| 项目 | 要求 | 原因 |
|---|---|---|
| **嘴巴** | **全程闭嘴**，嘴唇自然放松 | 嘴型由程序按声音生成。原视频里张嘴，会和生成的嘴打架 |
| 朝向 | 正脸或接近正脸，左右转头不超过 30 度 | 侧脸检测不准，嘴型也会变形 |
| 遮挡 | 手、话筒、头发都不要挡住嘴和下巴 | 被挡住的地方会被生成的嘴盖掉 |
| 时长 | 10 到 30 秒 | 太短动作重复明显，太长占内存、准备得更久 |

### 建议

| 项目 | 建议 | 原因 |
|---|---|---|
| 动作 | 轻微自然：眨眼、微微点头、轻微晃动 | 动作太大，脸部检测框会跳 |
| 画面 | 竖屏 9:16，720×1280 或 1080×1920 | 抖音直播是竖屏 |
| 脸的大小 | 脸部高度占画面高度的 1/4 到 1/3 | 模型只生成 256×256 的脸，脸在画面里太大，嘴部会比周围软 |
| 帧率 | 25 帧/秒 | 程序按 25 帧播放，30 帧的视频会显得稍慢 |
| 光线 | 均匀柔和，脸上没有强烈阴影 | 阴影会影响人脸分割 |
| 背景 | 静止，比如书架、纯色墙 | 背景动来动去，循环播放会更显眼 |

### 用 MuseTalk 时额外注意

- 尽量用**不留胡子**的形象。MuseTalk 会把嘴周围的胡子抹掉，说话和待机切换时很明显。
- 唇色不要太夸张，比如很红的口红。生成的嘴唇颜色会偏向自然色。

### 循环方式

待机视频会**先正放，再倒放**，来回循环，所以首尾不用刻意衔接。也正因为会倒放，**不要有方向性的动作**，比如头发被风往一个方向吹、走过来、抬手，倒放时会很怪。

### 视频从哪里来

**方式一：AI 生成虚拟人（推荐）**

先用文生图生成一张人像，再用图生视频（可灵、MiniMax、Wan 等）生成待机视频。没有肖像权问题，形象也可以按账号风格定制。

图生视频的提示词参考：

> 一位男性主播正对镜头，坐在书房里，嘴巴自然闭合，表情平静友好，偶尔轻微眨眼，头部有非常轻微的自然晃动，镜头固定不动，光线柔和均匀，背景静止。

生成后逐段检查：有没有张嘴、有没有突然的大动作、手有没有入画。有问题的片段剪掉，或者重新生成。

**方式二：自己或请人拍摄**

- 手机固定在三脚架上，竖屏，1080p，25 帧（或者拍完转成 25 帧）。
- 对着镜头放松坐好，嘴闭上，用鼻子呼吸，偶尔眨眼。录 30 秒左右，挑最稳的一段。
- 拍的是别人，要拿到对方的书面授权（肖像和用途都要写清楚）。

## 2. 生成形象

把视频放进项目目录，比如 `idle.mp4`，运行：

```bash
python -m avatarstream make-avatar --video idle.mp4 --out data/my_avatar --resize-height 1280
```

- `--resize-height 1280`：把 1080×1920 缩成 720×1280，直播时更省资源，画质也够用。
- 第一次运行会自动下载 85 MB 的人脸检测模型。
- 提示“太多帧没检测到人脸”：视频里侧脸或遮挡太多，换一段视频。
- 用 Wav2Lip 时下巴被切掉：加大下边距，`--pads 0 20 0 0`。

## 3. 生成 MuseTalk 数据

```bash
python -m avatarstream prepare-musetalk --avatar data/my_avatar
```

每个形象只做一次。在显卡上大约一两分钟，会生成脸部关键点、人脸编码和嘴部融合遮罩，存在 `data/my_avatar/musetalk/` 里。

**形象改过以后**，比如重新跑了 make-avatar，要重新运行这一步。程序发现数据和帧对不上时，会提示你。

## 4. 检查效果

最好用你自己录的一段话（wav 格式）来测，最接近直播时的样子：

```bash
python -m avatarstream render --engine musetalk --avatar data/my_avatar --audio 我的录音.wav --out output/my_test.mp4
```

看三个地方：

1. **嘴型和声音对不对得上**
2. **嘴部区域的位置**：嘴张得不够大，或者生成区域偏上偏下，就重新准备，加 `--bbox-shift`。正数往下挪，负数往上挪，每次调 5 左右：
   ```bash
   python -m avatarstream prepare-musetalk --avatar data/my_avatar --bbox-shift 5
   ```
3. **边缘有没有接缝**：主要看下巴和脸颊交界处。

满意以后，把 `scripts\start_live.bat` 里的 `AVATAR` 改成 `data\my_avatar`。

## 多个形象

可以准备好几个，比如不同衣服、不同场景，都放在 `data` 目录下，开播前改 `AVATAR` 就能切换。每个形象都要单独做第 3 步。`scripts\doctor.bat` 会列出所有形象，以及每个形象是否已经准备好 MuseTalk 数据。
