# 直播搭建指南

从零开始，把“你说话 → 数字人的声音和口型 → 直播间”搭起来。按顺序做，每一步做完都有检查方法。

## 0. 准备清单

| 东西 | 用途 | 来源 |
|---|---|---|
| NVIDIA 显卡，建议 12 GB 显存以上 | 变声和口型同时跑 | |
| 麦克风 | 你说话 | |
| VB-CABLE | 把变声后的声音传给程序和 OBS | https://vb-audio.com/Cable/ （免费） |
| 变声器：RVC 或 Seed-VC | 把你的声音实时换成数字人的音色 | 见第 2 步 |
| OBS Studio | 合成画面、推流 | https://obsproject.com/ |
| 抖音直播伴侣（如果在抖音开播） | 开播 | 抖音官方 |
| 本项目 | 实时口型 | 按 README 安装 |

## 1. 安装虚拟声卡

1. 下载 VB-CABLE，解压后**右键 `VBCABLE_Setup_x64.exe`，以管理员身份运行**，安装完重启电脑。
2. 安装后会多出两个设备：
   - `CABLE Input`：播放设备。往它里面“播放”的声音……
   - `CABLE Output`：录音设备。……会从这里“录”出来。
3. 检查：运行 `scripts\list_devices.bat`，列表里能看到 `CABLE Output`，类型是“输入”。

> 不要把 `CABLE Input` 设成系统默认播放设备，否则电脑里的所有声音都会进直播。

## 2. 安装变声器

两个开源方案任选一个。

| | RVC | Seed-VC |
|---|---|---|
| 项目地址 | https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI | https://github.com/Plachtaa/seed-vc |
| 怎么得到音色 | 用 10 分钟以上目标音色的干净录音训练一个模型 | 不用训练，给一段几秒到几十秒的参考音频 |
| 延迟和资源 | 延迟低、占用小、更成熟 | 更吃显卡，延迟更高 |
| 适合 | 长期使用固定的一个音色 | 想快速试很多音色 |

不管用哪个，实时变声界面里都这样设：

- **输入设备**：你的真实麦克风
- **输出设备**：`CABLE Input`
- 打开它的**监听**（或输出一份到耳机），你自己能听到变声后的效果
- 采样率选 48000 或 44100

检查：对着麦克风说话，耳机里听到的是变声后的声音。

> 音色必须有授权：自己训练的、AI 合成的、或明确授权给你使用的。不要用明星和其他真人的声音。

## 2.5 有两张以上显卡：分配任务（只有一张卡就跳过）

1. 双击 `scripts\setup_gpus.bat`。它会测出每张卡的算力和口型速度，然后一项项问你。
2. 变声器选你实际用的（RVC 或 Seed-VC）。看完推荐方案，直接回车就是接受，也可以输入别的编号。
3. 最后填变声器的启动脚本路径，例如 `D:\RVC\go-realtime-gui.bat`。
4. **以后都用 `scripts\start_voice_changer.bat` 启动变声器**，不要再直接双击原来的脚本，否则它可能又跑到别的卡上。口型程序会自动读取分配，不用改 `start_live.bat`。

检查：变声器和口型程序都开着、对着麦克风说话时，打开任务管理器的“性能”页，两张卡各自的 GPU 占用都在动，并且各管各的。

## 3. 启动口型程序

1. 用记事本打开 `scripts\start_live.bat`，确认 `INPUT_DEVICE=CABLE Output`，形象换成你的（可选）。
2. 双击运行。浏览器会打开状态页 `http://127.0.0.1:8010/status`。
3. 第一次启动时，看命令行里的这一行：
   ```
   每批 6 帧推理 xx ms（实时上限 240 ms），预计延迟约 xxx ms
   ```
   推理时间要明显小于实时上限，最好不超过它的一半，因为变声器也在用显卡。超过了就把 `BATCH` 改大，或者换更快的变声设置。
4. 检查：说话时状态页“说话”变成“是”，音量条在跳，预览里嘴在动；停下来以后嘴闭上，回到待机动作。

**没说话嘴也在动**：底噪太大。把 `VAD_DB` 从 -45 调到 -40 或 -38。
**说话时嘴不怎么动**：变声器输出音量太小。在变声器里调大输出，让说话时状态页的音量在 -30 到 -10 dB 之间。

## 4. 设置 OBS

### 画面

1. 来源里点 **+ → 浏览器**，新建一个叫“数字人”的源。
2. URL：`http://127.0.0.1:8010/`
3. 宽度和高度填形象的分辨率。示例形象 `glass_man` 是 720 × 1276，启动日志里也会打印。
4. **不要**勾选“当不可见时关闭源”，避免切换场景时画面断开。

也可以用虚拟摄像头：启动参数加 `--virtualcam`，在 OBS 里添加“视频采集设备”，选 OBS Virtual Camera。浏览器源更简单，推荐优先用它。

### 声音（偏移法，推荐先用这个）

1. 来源里点 **+ → 音频输入采集**，设备选 `CABLE Output`。
2. OBS 菜单 **编辑 → 高级音频属性**，找到这个源，把“同步偏移”设成状态页“OBS 同步偏移”的值（毫秒），例如 560。
3. 关掉 OBS 里你真实麦克风的源，不然会把原声也推出去。

### 检查音画同步

1. OBS 里点“开始录制”，对着麦克风清楚地说几句带“爸、跑、吗”这类闭嘴音的话，录 20 秒。
2. 回放录像，看嘴唇合上的瞬间和“b/p/m”的声音是否对得上。
3. 声音比嘴早，就把偏移加大 40 到 80 毫秒；声音比嘴晚，就减小。重录一次确认。

### 声音（转发法，追求严格对齐时用）

需要两条虚拟声卡（VB-CABLE A+B，或 Voicemeeter）：

1. 变声器输出到第一条：`CABLE Input`。
2. 启动参数加 `--audio-out-device "CABLE-A Input"`（名字以 `list_devices.bat` 显示为准）。
3. OBS 的音频输入采集选 `CABLE-A Output`，同步偏移保持 0。

程序会在显示每一帧的同一时刻，把这一帧对应的声音送出去，所以不需要再调偏移。

## 5. 推到直播间

- **抖音**：OBS 推流到直播伴侣，或者在直播伴侣里添加“窗口采集”采集 OBS 预览窗口，具体按直播伴侣当前版本的说明操作。开播前完成实名认证，按平台要求开启虚拟人/数字人相关的设置和标识。
- 在画面角落加一行文字，比如“本直播间主播为数字人形象，由真人实时驱动”。这样既满足 AI 生成内容标识的要求，也能减少观众误会。

## 6. 开播前检查

每次开播前花两分钟走一遍：

- [ ] 变声器在运行，耳机里是变声后的声音
- [ ] 状态页帧率稳定在 25 左右，“卡顿次数”不再增长
- [ ] 不说话时嘴是闭着的，说话时嘴在动
- [ ] OBS 录 20 秒回放，音画对齐
- [ ] OBS 里没有混入你的原声麦克风
- [ ] 直播间的数字人标识已经加上

## 常见问题

**启动时报“找不到名字里包含 CABLE Output 的输入设备”**
虚拟声卡没装好或没重启电脑。运行 `list_devices.bat` 看实际名字，把名字片段或编号填到 `INPUT_DEVICE`。

**状态页帧率低于 25、卡顿次数一直涨**
显卡忙不过来。按顺序试：确认加了 `--fp16`；把 `BATCH` 调大到 8；把变声器的质量参数调低；关掉其他占显卡的程序。

**画面里脸部有方框或边缘发虚**
把 `EXTRA` 设成 `--feather 0.12`，加大边缘羽化。如果是形象本身的人脸框不准，用 `--pads` 重新生成形象。

**嘴部比脸其他地方模糊**
这是 Wav2Lip 的固有限制：它只生成 256 × 256 的脸。缩小数字人在直播画面里的占比，模糊会不明显；用更高分辨率的口型模型是后续可以升级的方向。

**延迟太大，连麦时对方等太久**
把 `BATCH` 降到 4，延迟能降一百多毫秒，但显卡压力更大。
